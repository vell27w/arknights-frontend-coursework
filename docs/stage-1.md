# 第一阶段：页面、交互与资源优化

本项目是明日方舟游戏官网的非官方前端仿作。保留课设的内容范围：四名干员、每名干员一张立绘、独立演示登录页。没有后端接口、真实账号体系或游戏数据服务。

## 本阶段改动

- 15 个页面统一导航、当前页面状态、移动端菜单、返回入口与非官方作品说明。
- 根目录增加 `index.html`，打开项目地址即可进入首页。
- 原有重复样式和内联脚本集中到 `demo2/assets/site.css`、`demo2/assets/site.js`。
- 手机、平板和桌面布局支持；公告正文、更多内容卡片与衍生页面可滚动阅读。
- 情报轮播完整显示四张图片，支持上一张、下一张、暂停；鼠标悬停、键盘聚焦、页面隐藏时不自动切换，减少动态效果设置下默认暂停。
- 情报分类支持键盘方向键、Home、End；干员按钮支持点击与方向键切换。
- 世界观从悬停展示改为按钮选择，默认展示第一项，支持触屏与键盘。
- 登录表单在页面内反馈空值、演示说明勾选和成功状态；不发送、不存储输入，不伪造登录会话。
- 修复历史通讯详情入口；没有收录的详情标记为“未收录详情”，集成战略标记为“仅展示封面”。
- 泰拉万象增加世界观、干员与衍生内容入口；衍生页删除无功能的菜单或查询按钮。
- 补齐中文语言、页面标题、主要内容区域、图片说明、焦点样式和安全的新窗口链接。
- 22 张较大图片改用 WebP，文件总大小由 12,850,972 字节减少至 2,074,640 字节，减少约 83.9%。此数据是图片文件体积对比，不是页面性能评分。
- 从原背景视频提取静态封面。手机、小屏幕、节省流量或减少动态效果模式默认不请求视频；桌面符合条件时静音播放。支持手动播放、暂停、声音开关和加载失败反馈。

## 本地查看

无需安装前端框架或构建工具。在仓库根目录运行：

```sh
python -m http.server 4173 --bind 127.0.0.1
```

打开 `http://127.0.0.1:4173/`。大部分页面也可直接打开 `demo2/main.html`；分享链接等浏览器能力建议通过本地服务器使用。

## 验证方法

安装可选的测试依赖后，在上述本地服务器运行时执行：

```sh
npm install
npm test
```

测试默认使用已安装的 Microsoft Edge。也可以设置 `BROWSER_CHANNEL=chrome` 使用本机 Chrome。测试依赖用于验证，不影响静态网页运行。

自动检查覆盖 15 个页面在 320、390、768、1440 像素宽度下的横向溢出、图片加载与页面脚本错误，以及导航、干员、世界观、情报分类、轮播、视频控制和演示表单。截图和检查结果生成于 `artifacts/stage1/`，不提交到仓库。

2026-10-07 使用本机 Microsoft Edge 完成验收：60 组页面与视口检查、上述交互检查全部通过；内部链接与资源路径检查通过。已人工查看首页、干员、情报、世界观与更多内容页面的截图。

## 保留的边界

- 原视频仍约 35 MB，本阶段改变加载策略，未重新编码压缩。用户主动播放仍会请求原视频。
- 手机检查通过浏览器视口模拟，尚未在真实 iOS、Android 设备和 Safari、Firefox 中测试。
- 公告与宣传内容是课设历史资料，不代表游戏当前活动或开放时间。外部阅读、追番、下载链接由第三方维护。
- 本阶段不配置 GitHub Pages、不编写最终项目 README，也不接入个人博客；这些属于后续展示阶段。
- 本阶段会独立提交并标记为 `stage-1`；原课设可在 `coursework-original` 标签中查看。
